每条决策一个小节。状态取值：`提议`、`已接受`、`已被取代（见 ADR-xxxx）`、`已否决`。推翻旧决策时
新增一条，不删除历史。

## ADR-0001 产品定位：单用户远程访问优先

- 状态：已接受
- 日期：2026-10-27
- 关联：[产品文档](01-product.md)

### 背景
远程桌面有"多用户并行"（Wolf）和"单用户远程访问"（RDP）两类目标。Sunshine 面向后者，但只能复制
已登录的本地桌面，远程使用依赖本地显示器和本地登录。

### 决策
Prism 优先实现单用户远程访问的 RDP 模型：登录前可用、远程会话独立于物理座位、断开保留。多用户
并行列为远期目标（M6），当前设计不得阻碍它（会话按用户划分，不假设全局只有一个用户）。

### 后果
- 需要系统级组件和会话管理（ADR-0002、ADR-0003）。
- 多用户的端口复用、设备隔离等问题推迟。

## ADR-0002 Prism 作为系统级服务：prismd + 会话代理

- 状态：已接受（方向）；helper 与 PAM 细节待 S3
- 日期：2026-10-27
- 关联：Q7、Q11、M3

### 背景
用户级服务挂在 `graphical-session.target` 上，本地不登录就不运行。开启 linger 可以绕过，但不能创建
真正的登录会话，也无法支持多用户。

### 决策
- `prismd` 以专用系统用户 `prism` 运行，负责网络面（配对、应用列表、启动、Web UI）、认证和会话代理器。
- 特权操作（打开 PAM 会话、在 `user@UID` 中启动单元）由接口极小的 root 辅助进程完成。
- 采集、编码、音频、输入、启动应用由以用户身份运行在会话内的会话代理完成。
- 已配对设备须绑定到 Linux 用户才能建立会话；可选 PIN 或系统密码。

### 备选方案
- **linger + 用户级服务**：成本最低，但不是真正的登录会话，无法多用户；作为 M2 的过渡验证手段保留。
- **prismd 以 root 运行全部功能**：攻击面过大，且以 root 访问用户的 PipeWire 和 Wayland 很别扭。

### 后果
- 需要 IPC、迁移、系统级打包（M3）。
- 与 Windows 版 Sunshine、GNOME 远程登录的结构一致，便于参考。

## ADR-0003 一个用户一个图形会话：有则接入，无则新建

- 状态：已接受
- 日期：2026-10-27
- 关联：Q5、Q14、T2.2、T2.7

### 背景
Linux 上一个用户只有一个 systemd 用户管理器和一个会话总线，桌面环境普遍不支持同一用户同时运行两个
图形会话。RDP 的做法是远程登录时强制注销本地会话，对工作连续性不友好。

### 决策
- 用户有本地会话时，远程接入该会话，以虚拟屏幕的形式出现（现有 Desktop (Virtual) 能力）。
- 用户没有会话时，新建远程会话；有断开的远程会话时接入它。
- 提供"注销本地、远程重开"作为可选操作。

### 备选方案
- **强制注销本地（RDP 方式）**：打断工作，否决。
- **同一用户并行两个桌面 + 私有 D-Bus 隔离**：Plasma 等桌面不支持，配置文件互写，否决；私有 D-Bus
  只保留给过渡期的隔离 headless 应用模式。

### 后果
- 远程会话存在时本地登录仍是冲突点，由 M4 处理（ADR 待 S4 后补充）。

## ADR-0004 远程会话运行完整桌面环境，放弃手工拼装外壳

- 状态：已接受
- 日期：2026-10-27
- 关联：P2、T2.3

### 背景
早先的方案是在 headless labwc 上用 autostart 拼装面板、启动器、通知、polkit 代理等。

### 决策
远程会话运行完整的桌面环境（默认 Plasma），`labwc-minimal` 作为兜底选项。

### 后果
- 面板、启动器、文件对话框、通知、输入法、polkit 代理全部由桌面环境提供。
- 需要解决桌面环境在 headless 或嵌套模式下的运行问题（ADR-0005）。

## ADR-0005 远程会话的合成结构

- 状态：提议
- 日期：2026-10-27
- 关联：Q1–Q4、S1、S2、T2.3

### 背景
完整桌面需要一个合成器；Prism 需要采集它的输出并注入输入。

### 候选
- **嵌套**：外层 `prism-labwc`（headless 输出、screencopy、虚拟输入、HDR 补丁）+ 内层完整桌面作为
  外层的 Wayland 客户端。参考 Wolf（gst-wayland-display + sway/gamescope/XFCE）。
- **直连 KWin headless**：`kwin_wayland --virtual`，采集用现有 `kwingrab.cpp`，输入走 EIS 或 fake input。

### 当前倾向
嵌套：采集、输入、HDR 只实现一次，桌面环境无关。最终以 S1/S2 的延迟、HDR、输入数据为准。

## ADR-0006 私有 D-Bus 只用于隔离 headless 应用模式

- 状态：已接受
- 日期：2026-10-27
- 关联：P3、ADR-0003

### 背景
文件对话框弹到物理屏幕的原因是 headless 会话共用本地会话的 D-Bus 和 portal。

### 决策
远程会话是用户唯一的会话，使用用户真实的会话总线，由桌面环境按常规导入环境；不引入私有总线。
过渡期保留的隔离 headless 应用模式如需修复对话框问题，才使用 `dbus-run-session` 式的私有总线。

## ADR-0007 客户端"退出"的语义

- 状态：提议
- 日期：2026-10-27
- 关联：Q10、S5、T2.4

### 当前倾向
`session` 模式下，客户端"退出"默认等于断开（会话保留），可配置为同时注销；应用退出不影响会话。
需要 S5 确认原版 Moonlight 和 Iris 在这种语义下的表现。
