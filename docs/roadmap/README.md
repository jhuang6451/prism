# Prism 远程会话升级规划

本目录是 Prism 从"远程显示复制器"升级为"真正的远程桌面主机"的规划文档。它记录产品定位、
目标架构、项目规范、任务拆解、核心问题与测试要点，以及已经做出的决策。后续开发按这里的任务
一步一步推进，每完成一项就回来更新状态。

> 规划文档使用中文；代码、注释、doxygen、用户文档（`README.md`、`docs/*.md`）、Web UI 文案和
> 提交信息仍使用英文，见 [项目规范](03-conventions.md)。

## 一句话目标

**只要主机开着，就能从任何 Moonlight/Iris 客户端登录到自己的完整桌面或游戏模式；
与本地是否登录、是否接显示器无关；断开后会话保留，回来接着用。**

## 每个任务的工作流

1. 在 [04-tasks.md](04-tasks.md) 找到任务卡片，确认依赖已完成，把状态改为 `进行中`。
2. 若任务涉及卡片里标注的待定决策，先在 [decisions.md](decisions.md) 把对应 ADR 定下来。
3. 从 `master` 拉出分支（命名见 [项目规范](03-conventions.md#2-分支提交与协作)）。
4. 实现、补测试、跑 `scripts/lint.sh` 和 `test_prism`，满足[完成标准](03-conventions.md#12-完成标准definition-of-done)。
5. 同步更新受影响的用户文档和本目录文档（任务状态、问题清单、ADR）。
6. 提交；只有在用户要求时才推送或开 PR，且只在 `jhuang6451/prism` 上开。

## 术语表

| 术语 | 含义 |
|---|---|
| 宿主机（host） | 运行 Prism 的电脑。可以没有显示器。 |
| 客户端（client） | Moonlight 或 Iris（用户自己的 Moonlight 衍生客户端）。 |
| 本地会话（local session） | 用户在物理座位上通过显示管理器（SDDM、Plasma Login Manager 等）登录的图形会话。 |
| 远程会话（remote session） | 由 Prism 创建并拥有、不绑定物理座位的图形会话。断开后保留。 |
| 接入（attach） | 把串流连接到一个已存在的会话。对本地会话而言，就是给它加一块虚拟屏幕。 |
| 新建（spawn） | 为用户创建一个新的远程会话。 |
| 断开（detach） | 串流结束，但会话继续存在。 |
| 注销（end） | 会话结束，其中的应用全部退出。 |
| 外层合成器（outer compositor） | Prism 持有的 headless 合成器，负责虚拟输出、采集和输入注入。当前是 `prism-labwc`。 |
| 内层桌面（inner desktop） | 作为外层合成器的 Wayland 客户端运行的完整桌面环境，例如嵌套的 Plasma。 |
| `prismd` | 计划中的系统级服务：配对、认证、Web UI、会话代理。 |
| 会话代理（session agent） | 以用户身份运行在会话内的 Prism 串流进程：采集、编码、音频、输入、启动应用。 |
| 捕获模式（capture mode） | 现有的按应用设置：`default`（镜像）、`virtual`、`headless`、`portal:<output>`。 |
