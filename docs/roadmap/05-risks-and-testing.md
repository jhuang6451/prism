## 2. 风险登记

| 风险 | 可能性 | 影响 | 应对 |
|---|---|---|---|
| 嵌套带来的延迟或 HDR 问题无法接受 | 中 | 高 | S1/S2 并行做，保留直连 KWin 的备选；游戏场景可保留现有 Steam Headless 路径 |
| Plasma 在嵌套或 headless 模式下不稳定 | 中 | 高 | 内层桌面可选（`labwc-minimal` 兜底）；跟踪 KDE 上游（Plasma 6.9 计划提供 headless 多会话） |
| KDE 上游（Plasma Login Manager + KRdp）提供同类能力 | 中 | 中 | Prism 的差异是 Moonlight 协议、游戏、HDR、低延迟；架构上保持可接入上游的 headless 会话 |
| 系统服务扩大攻击面 | 中 | 高 | 网络面非 root、root helper 接口极小、systemd 加固、T3.7 安全审查 |
| 拆分 prismd/代理改动上游文件过多，导致同步困难 | 中 | 中 | 接缝最少原则，里程碑末期演练同步 |
| 原版 Moonlight 客户端的语义限制（单应用、退出） | 高 | 中 | 服务器端适配；需要协议扩展的功能只在 Iris 上提供 |
| 测试需要 logind/PAM/GPU，CI 无法覆盖 | 高 | 中 | 纯逻辑最大化单元测试；VM 端到端（T0.3）；硬件手动清单 |
| 用户本地 Plasma 被 Prism 操作影响（接入模式） | 低 | 高 | 只动有记录的资源；失败即关闭；回滚测试 |

## 4. 测试要点

### 4.1 会话状态机与策略
- 状态 × 事件的全部组合，包括非法转换被拒绝。
- 策略表每一行；用户未绑定；本地和远程会话同时存在的异常；另一客户端正在串流时的抢占配置。
- prismd 重启后从 logind 和状态文件重建，结果与重启前一致。
- 状态文件损坏、版本不符、会话 ID 不符、字段多或少时拒绝。

### 4.2 远程会话生命周期
- 新建：每个就绪阶段单独超时，超时后完整回滚，无残留。
- 断开再接入：窗口、未保存内容、音频路由不变；分辨率不同的客户端接入时输出模式跟随。
- 注销的四种来源（桌面内、Web UI、空闲超时、本地登录策略）都能干净结束。
- 崩溃：分别杀掉代理、输入桥、外层、内层，行为符合 Q18 的预期。
- 清理脚本重复运行无副作用；遇到无法清理的已确认资源时阻止启动。

### 4.3 隔离与应用联动（对应原始问题）
- 文件对话框：GTK 应用、Qt 应用、Flatpak 应用、Xwayland 应用打开"选择文件"，对话框出现在远程画面。
- `xdg-open` 链接在远程会话的浏览器打开；通知出现在远程会话。
- 单实例应用（Firefox、Dolphin）重复启动时激活已有窗口。
- 两个同步应用之间拖放文件、复制粘贴。
- 接入模式下以上行为与本地桌面一致。

### 4.4 输入
- 键盘：中英文布局、组合键、Super/Alt+Tab 进入内层而不是被外层吃掉。
- 鼠标：绝对与相对模式切换；FPS 游戏的指针锁定；滚轮（含高精度）；光标形状与隐藏。
- 手柄：Xbox、DualSense、DualSense Edge（含背键），Steam Input 识别；热插拔。
- 触屏客户端：触控模拟鼠标。
- 本地键鼠在远程会话中不可见（无本地会话时）；接入模式下本地键鼠仍然可用。

### 4.5 画面与性能
- 分辨率和刷新率完全匹配客户端（1080p60、1440p120、4K60、4K120）。
- HDR：HEVC Main10 与 AV1 10-bit；SDR 桌面与 HDR 游戏切换；Headless HDR 校准仍然生效。
- 延迟、CPU/GPU 占用与 T0.2 基线对比，嵌套结构的额外开销需量化并记录。
- 长时间（≥ 2 小时）串流无内存增长、无帧率下降。

### 4.6 音频
- 远程会话的声音只进串流，不从宿主扬声器播放。
- 接入模式沿用现有虚拟/镜像模式的路由，结束后恢复默认 sink（含 `prism_default_sink`）。
- 断开期间远程会话里播放的声音不泄漏到宿主扬声器。

### 4.7 安全
- 未配对设备、已配对但未绑定的设备、绑定到其他用户的设备，分别尝试新建和接入会话。
- PIN 错误限速和锁定。
- IPC：伪造对端身份、发送超长或未知字段消息、跨会话操作，全部被拒绝。
- helper 只接受 `prism` 用户；参数注入（用户名、单元名含特殊字符）被拒绝。
- 日志和状态文件中没有 `rikey`、PIN、私钥。
- `systemd-analyze security prismd.service` 评分记录在案。

### 4.8 安装与迁移
- 全新安装、从用户级安装迁移、升级、卸载（保留配置与凭据）。
- 迁移后配对设备无需重新配对；apps.json、app-sync 选择、HDR 校准保留。
- 用户级模式在 M3 之后仍能单独工作。

### 4.9 兼容性回归
- Desktop (Mirror)、Desktop (Virtual)、portal 模式、隔离 headless 应用、Steam Headless 的行为与当前
  版本一致（M2/M3 期间每个 PR 都要跑现有测试）。
- 上游同步演练无大面积冲突。

## 6. 性能指标

| 指标 | 测量方法 | 目标 |
|---|---|---|
| 新建会话耗时（点击到首帧） | 客户端计时 + Prism 日志时间戳 | ≤ 15 秒（不含认证输入） |
| 接入已有会话耗时 | 同上 | ≤ 3 秒 |
| 主机处理延迟 | Moonlight/Iris 统计叠加层 | 不高于 T0.2 基线 + 1 ms |
| 空闲桌面的 GPU 占用 | `nvidia-smi dmon` | 记录并与 Steam Headless 对比，不设硬指标 |
| 断开状态下的资源占用 | `systemd-cgtop` | 记录；T5.5 后可降级 |
